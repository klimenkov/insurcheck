# Linear Project Setup & Task Backlog for InsurCheck

Этот документ содержит полную структуру для настройки рабочего пространства в **Linear** ([linear.app](https://linear.app)) и бэклог задач, сформированный на основе текущего состояния продукта и заметок Саши.

---

## 1. Рекомендуемая структура Workspace в Linear

* **Team Name:** `InsurCheck`
* **Team Identifier (Key):** `INS` (задачи будут иметь вид `INS-1`, `INS-2` и т.д.)
* **Workflow Statuses:**
  * 📥 `Backlog` (Идеи и запланированные фичи)
  * 📋 `Todo` (Отобрано в текущий спринт)
  * 🚧 `In Progress` (В активной разработке)
  * 🔍 `In Review` (Запушено на Staging / Render, тестируется Сашей)
  * ✅ `Done` (Принято и работает в проде)
* **Cycles (Спринты):** включить **1-недельные циклы** (1 Week Cycles). Для борьбы с расфокусом недельные спринты работают в 3 раза лучше, чем 2-недельные.

---

## 2. Проекты (Epics) и список задач

### 🛡️ Project 1: Admin Dashboard & Data Quality (Качество данных и Админка)

#### [INS-1] Защищенная панель модератора `/admin`
* **Приоритет:** High (P1)
* **Статус:** Todo
* **Описание:** 
  Создать защищенный интерфейс для просмотра всех сабмитов водителей (`submissions`), отзывов (`reviews`) и сообщений обратной связи (`contact_messages`).
* **Критерии приемки (DoD):**
  - Авторизация по PIN/паролю администратора.
  - Таблица сабмитов с пагинацией и поиском.
  - Кнопки: «Одобрить», «Скрыть из выдачи», «Удалить».
  - Возможность редактировать текст отзыва и опечатки в названии страховщика.

#### [INS-2] Автоматическая фильтрация и отсечение аномалий ($10 / $9999)
* **Приоритет:** Urgent (P0)
* **Статус:** Todo
* **Описание:**
  Внедрить правила валидации (Sanity Clamping) на бэкенде и фронтенде, чтобы предотвратить загрязнение актуарного бенчмарка мусорными данными.
* **Критерии приемки (DoD):**
  - Входная ежемесячная премия ограничена диапазоном `$50 – $1,200/мес`.
  - Значения вне диапазона отклоняются с понятной подсказкой пользователю.
  - При попытке ввести подозрительные данные сабмит отправляется в статус `flagged_for_review` вместо автоматической публикации.

#### [INS-3] Fuzzy Matching и авто-нормализация названий страховых
* **Приоритет:** High (P1)
* **Статус:** Todo
* **Описание:**
  При сохранении пользовательских данных сопоставлять свободный ввод с 15 каноническими страховщиками Онтарио.
* **Критерии приемки (DoD):**
  - Таблица синонимов: `td`, `meloche`, `тд` → `TD Insurance`; `belair`, `белэйр` → `Belairdirect`.
  - Если совпадение не найдено, сохраняется как `Other` с оригинальной строкой для последующей модерации в админке.

### 🧠 Project 2: Smart Recommendation Algorithm (Алгоритм подбора под профиль)

#### [INS-4] Актуарная когортная сегментация (Driver Segmentation Model)
* **Приоритет:** High (P1)
* **Статус:** Backlog
* **Описание:**
  Разработать алгоритм кластеризации базы данных (по накоплению 300–500+ записей) для выявления сильнейших страховщиков под конкретный сегмент.
* **Критерии приемки (DoD):**
  - Определение когорт:
    * Новичок (G2 / стаж < 3 лет / возраст 16–24)
    * Семейный прайм-водитель (G / 30–55 лет / SUV)
    * Житель GTA High-Theft зоны (Brampton, Vaughan, Mississauga)
    * Житель регионов с низким риском (Ottawa, London, Kingston)
  - Расчет медианной ставки и индекса удовлетворенности (`Value for Money`) для каждой когорты.

#### [INS-5] Персонализированный блок рекомендаций в ResultCard
* **Приоритет:** Medium (P2)
* **Статус:** Backlog
* **Описание:**
  После прохождения Sanity Check показывать карточку с рекомендацией наиболее выгодного для данного профиля страховщика.
* **Критерии приемки (DoD):**
  - Вывод текста: *«Для водителей вашего возраста в регионе Ottawa лучшим соотношением цена/качество по данным 84 отзывов обладает Desjardins (~$172/mo).»*
  - Кнопка прямого перехода к отзывам или официальному сайту страховщика.

### 🕷️ Project 3: Data Harvesting & Market Watch (Сбор котировок)

#### [INS-6] Расширение парсера на Sonnet и Belairdirect
* **Приоритет:** Medium (P2)
* **Статус:** Backlog
* **Описание:**
  Сейчас скрапер собирает данные только со Square One. Добавить headless-агенты для сбора публичных онлайн-котировок Sonnet и Belairdirect по фиксированным тестовым персонам.
* **Критерии приемки (DoD):**
  - Скрипт Playwright для заполнения формы Sonnet.
  - Сохранение котировки в `scraped_quotes` с привязкой к `persona_id`.
  - Запуск по расписанию 1 раз в месяц для отслеживания динамики цен.

#### [INS-7] Интеграция ежеквартальных отчетов FSRA Rate Approvals
* **Приоритет:** Medium (P2)
* **Статус:** Backlog
* **Описание:**
  Использовать открытые данные FSRA по одобренным индексациям тарифов (Rate Approvals) для калибровки актуарного движка.
* **Критерии приемки (DoD):**
  - Модуль в `server/engine/ontarioData.js` с датами и процентами последних изменений ставок по топ-15 компаниям.
  - Отображение бейджа в карточке компании: *«FSRA Rate Change Q2: +3.4%»*.

### 🌐 Project 4: Infrastructure, Domain & Launch (Инфраструктура и запуск)

#### [INS-8] Подключение кастомного домена (`insurcheck.ca` / `insurcheck.com`)
* **Приоритет:** Urgent (P0)
* **Статус:** Todo
* **Описание:**
  Купить домен и привязать к Render через Cloudflare DNS для обеспечения доверия канадских пользователей.
* **Критерии приемки (DoD):**
  - Домен зарегистрирован.
  - Настроены CNAME/A записи в Cloudflare.
  - Автоматический SSL-сертификат и редирект с HTTP на HTTPS.

#### [INS-9] OpenGraph мета-теги и превью для шеринга в соцсетях
* **Приоритет:** Medium (P2)
* **Статус:** Todo
* **Описание:**
  Сделать красивые карточки предпросмотра при отправке ссылки в Telegram, WhatsApp, Reddit и LinkedIn.
* **Критерии приемки (DoD):**
  - Теги `og:title`, `og:description`, `og:image`.
  - Картинка с бенчмарком Онтарио и логотипом InsurCheck.

#### [INS-10] Интеграция легковесной веб-аналитики (PostHog / Umami)
* **Приоритет:** Low (P3)
* **Статус:** Backlog
* **Описание:**
  Подключить приватную аналитику без тяжелых куки, чтобы видеть конверсию: сколько людей зашли → посчитали → поделились ставкой → кликнули на брокера.
