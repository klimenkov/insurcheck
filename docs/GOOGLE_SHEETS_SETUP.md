# Инструкция: Настройка резервного копирования в Google Таблицу (Append-Only)

Этот механизм позволяет в реальном времени сохранять все действия пользователей (**сабмиты тарифов, отзывы, заявки на waitlist брокеров, обратную связь и контакты**) напрямую в вашу личную Google Таблицу.

### Ключевые преимущества:
1. **100% защита от случайного удаления:** У скрипта есть права только **добавлять строки** (`appendRow`). У бэкенда и у AI нет доступа к Google-аккаунту и нет API-методов на удаление или изменение существующих строк.
2. **Изолированность:** Даже при полном сбое или пересоздании сервера база данных в вашей Google Таблице остаётся нетронутой.
3. **Безотказность:** Отправка вебхука асинхронная и неблокирующая. Если Google временно недоступен, пользователи сайта не заметят задержек.

## Пошаговая настройка за 2 минуты

### Шаг 1: Создайте новую Google Таблицу
1. Откройте [sheets.new](https://sheets.new) в браузере.
2. Назовите таблицу, например: `InsurCheck Production Backup`.

### Шаг 2: Вставьте код скрипта
1. В верхнем меню таблицы нажмите: **Расширения** (Extensions) -> **Apps Script**.
2. Удалите стандартный код из редактора (`function myFunction() { ... }`).
3. Скопируйте и вставьте весь код из файла [`scripts/google_apps_script.js`](file:///c:/Users/klimenkov/Projects/Active/insurcheck/scripts/google_apps_script.js).
4. Нажмите значок дискеты **Сохранить проект** (Save project / Ctrl+S).

### Шаг 3: Разверните как веб-приложение
1. В правом верхнем углу нажмите синюю кнопку **Начать развертывание** (Deploy) -> **Новое развертывание** (New deployment).
2. Нажмите на значок шестеренки слева от «Выберите тип» и выберите **Веб-приложение** (Web app).
3. Заполните параметры:
   - **Описание (Description):** `InsurCheck Webhook`
   - **Запуск от имени (Execute as):** `Я (ваш_email@gmail.com)`
   - **У кого есть доступ (Who has access):** `Все (Anyone)`
4. Нажмите **Начать развертывание** (Deploy).
5. При первом запуске Google попросит подтвердить доступ:
   - Нажмите **Предоставить доступ** (Authorize access) -> выберите свой аккаунт.
   - Если появится предупреждение «Google hasn’t verified this app», нажмите **Advanced** (Дополнительно) -> **Go to Untitled project (unsafe)** -> **Allow** (Разрешить).
6. Скопируйте полученный **URL веб-приложения** (Web app URL).  
   *Пример ссылки: `https://script.google.com/macros/s/AKfycby.../exec`*

### Шаг 4: Подключите переменную окружения
1. В локальном файле `.env` добавьте:
   ```env
   GOOGLE_SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/ВАШ_URL/exec
   ```
2. В панели **Render Dashboard**:
   - Перейдите в ваш сервис `insurcheck` -> **Environment**.
   - Добавьте переменную `GOOGLE_SHEETS_WEBHOOK_URL` с этим же значением.
   - Нажмите **Save changes**.

## Синхронизация уже имеющихся данных с продакшена
Чтобы сразу выгрузить в таблицу все существующие 3 сабмита, отзывы и лиды, запустите команду:
```bash
python scripts/sync_to_google_sheets.py https://script.google.com/macros/s/ВАШ_URL/exec
```

В таблице автоматически создадутся и красиво отформатируются вкладки:
* **All Events** — хронологический лог всех событий с полным JSON.
* **Submissions** — таблица сабмитов (FSA, авто, год, возраст, стаж, премия, страховая).
* **Broker Waitlist** — список email для уведомления о запуске брокеров.
* **Reviews** — отзывы о страховых компаниях с оценками по 5 критериям.
* **Feedback** — оценки точности бенчмарка.
* **Contact Messages** — сообщения из формы контактов.
